# Automate the Boring Stuff with Python

This repository contains comprehensive Python learning materials based on the "Automate the Boring Stuff with Python" course.

## 📚 Contents

The main learning content is contained in `desktop.ipynb`, a Jupyter notebook covering:

### Core Python Concepts
- **Functions and Scope**: Function definitions, global variables, and best practices
- **Control Flow**: Loops, conditionals, and logical operations  
- **Data Structures**: Lists, dictionaries, and string manipulation
- **Error Handling**: Try-except blocks, logging, and debugging techniques

### Practical Applications
- **File Operations**: Reading, writing, and manipulating files
- **Regular Expressions**: Pattern matching and text processing
- **Web Scraping**: Using requests and BeautifulSoup for data extraction
- **Email Automation**: Secure email sending with proper authentication
- **System Operations**: OS module usage, file system navigation

### Advanced Topics
- **Recursion**: Understanding recursive functions with practical examples
- **Character Analysis**: Frequency counting and text analysis
- **Game Development**: Interactive number guessing game with error handling

## 🚀 Getting Started

1. **Prerequisites**: Python 3.x and Jupyter Notebook
2. **Installation**: Clone this repository and install required packages:
   ```bash
   git clone https://github.com/username/Automate-the-boring-stuff-with-python.git
   cd Automate-the-boring-stuff-with-python
   pip install jupyter requests beautifulsoup4
   ```
3. **Usage**: Open the notebook:
   ```bash
   jupyter notebook desktop.ipynb
   ```

## 📋 Learning Path

The notebook is structured progressively, starting from basic concepts and building up to more complex applications. Each code cell includes:
- Detailed comments explaining the logic
- Error handling best practices
- Practical examples and use cases
- Security considerations where applicable

## 🛠️ Best Practices Implemented

- **Code Quality**: Proper variable naming, function documentation, and error handling
- **Security**: Environment variables for sensitive data, proper password handling
- **Pythonic Code**: Use of f-strings, enumerate(), context managers, and proper exception handling
- **Documentation**: Comprehensive docstrings and inline comments
